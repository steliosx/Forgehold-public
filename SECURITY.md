# Security

This is a source preview; no production deployment is currently supported by this repository. Unit tests do not establish a security boundary around untrusted workloads.

For a suspected vulnerability, use the repository's private vulnerability reporting option in the Security tab when available. If that option is unavailable, open an issue containing only a request for a private reporting channel; do not include exploit details, credentials, private logs or customer data. Do not post secrets in public issues or pull requests.
